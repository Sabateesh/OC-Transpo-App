# OC Transpo

An iPhone app for nearby departures, destination-based trip planning, service alerts, and journey guidance in Ottawa.

## Open the app

1. Copy `Shared/Secrets.swift.example` to `Shared/Secrets.swift`.
2. Add your OC Transpo API subscription key to the copied file. The key file is ignored by Git.
3. Open `OCTranspo.xcodeproj` in Xcode and run the `OCTranspo` scheme.

The app includes a prepared timetable for scheduled trips. A current API key is needed for live departures and vehicle positions.
